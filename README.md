## Instrukcja uruchomienia

Pobierz, rozpakuj i przejdź w konosli do wypakowanego folderu. Kolejno uruchom dane polecenie

```bash
npm install
```

```bash
npm run dev
```

Aplikacja powinna być widoczna pod tym adresem [http://localhost:3000](http://localhost:3000)

## Dodatkowe informacje

W pliku app/components/LiveMatches.txs można zmienić wartość 10000 na mniejszą, aby widzieć częściej zmiany, albo if (Math.random() > 0.1) return match; wartość 0.1 ustawić na większą, aby wieksza ilość kursów się zmieniała.
